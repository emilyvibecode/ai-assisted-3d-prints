# AI-assisted 3D prints

Two personal fabrication projects: a Mac mini enclosure with an integrated phone stand, and a mixed-material architectural miniature.

| Project | Included | Current status |
| --- | --- | --- |
| [Mac mini enclosure + phone stand](mac-mini-enclosure/) | Build overview and missing-file checklist | Printed build described in project notes; original fabrication files not recovered |
| [Miniature house](miniature-house/) | Current mesh set, editable geometry source, part manifest and assembly guidance | User reports all project pieces printed; final assembly and exact per-file print provenance unverified |
| [Experimental garage roof](miniature-house/experimental/r6-garage-roof/) | One replacement candidate | Mesh-checked only; not sliced, printed or physically fit-tested |

Start with the project README before opening models. House dimensions are millimeters at working scale 1:120. STL does not encode units or printer settings. Source, current exported models and experimental candidates are kept separate.

This initial release contains no photographs, screenshots, reference images, embedded thumbnails, slicer archives or printer instructions. Mesh checks and successful source execution do not prove physical fit or printer readiness.
